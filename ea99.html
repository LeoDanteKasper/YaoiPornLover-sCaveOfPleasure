🎮 Reproductor de Juegos SWF 🎮

Selecciona un archivo y presiona "Cargar y Jugar"
El emulador Ruffle se iniciará automáticamente

💡 Nota técnica: Este reproductor utiliza Ruffle y consulta la API de GitHub para listar automáticamente todos los archivos .swf presentes en la rama main de este repositorio.

⚠️ Si acabas de subir un juego nuevo y no aparece, espera 1-2 minutos (la caché de la API de GitHub) o escríbelo manualmente en el campo de texto.
